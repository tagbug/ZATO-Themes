# Third-party material

## GNOME Shell

`vendor/gnome-shell-50/gnome-shell-dark.css` is the GNOME Shell 50.5 dark stylesheet supplied by Fedora 44.
Its original copyright and LGPL-2.1-or-later notice are retained. The licence text is in `vendor/gnome-shell-50/COPYING.LIB`.

Generated Shell styles include this base CSS and the project's colour changes and overrides.
Upstream project: https://gitlab.gnome.org/GNOME/gnome-shell

GTK 3 companions import the installed Adwaita stylesheet by resource URI; GTK's stylesheet is not copied into the GTK companion files.

## Fonts

The styles reference `BoYa-Courier-Mix` and `KingHwaOldSong-GB` as optional installed fonts.
No font files or font outline paths are distributed.

The fonts used for the screenshots identify the following copyright holders in their metadata:
